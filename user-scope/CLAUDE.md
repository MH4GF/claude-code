# コメントと文書

コードコメント・docs・SKILL.md・設定ファイルのコメント・ノートは、いま読む人のためのスナップショット。コードや規約が現在どうなっていて、なぜその形なのかだけが載っている。

情報にはそれぞれ置き場所がある。何がいつ何から変わったかはコミットメッセージと PR 本文に、タスクやレビュー指摘の参照は issue に、結論に至った過程 (試した案、却下した代替、probe の出力) は PR 本文か ADR に書く。

コメントを残すかは「このコメントが無い状態でこの行を変える読み手は、コードが表現できない何かを壊すか」で決める。壊すなら残す (隠れた制約、上流バグによる pin とその外せる条件、読み手が驚く挙動)。

例: 「独立 wiki は旧方式のタグ分類法のままでよく」→「独立 wiki はタグのみの分類法を使う」
