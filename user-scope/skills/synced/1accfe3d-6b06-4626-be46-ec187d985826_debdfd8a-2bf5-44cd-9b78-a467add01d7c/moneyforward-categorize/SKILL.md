# Money Forward ME 未分類カテゴリ修正スキル

Money Forward MEの入出金一覧から未分類の取引を見つけ、ユーザーと相談しながら正しいカテゴリ（大項目・中項目）を設定するスキル。

## 前提知識

Money Forwardのカテゴリは**2階層**で構成されている:

- **大項目**（例: 食費、通信費、趣味・娯楽）
- **中項目**（例: 外食、カフェ、食料品）

重要な挙動として、大項目を変更すると中項目は自動的に「その他○○」にリセットされる。そのため、大項目と中項目の両方を正しく設定するには2回のドロップダウン操作が必要になる。

## ワークフロー

### Step 1: Money Forwardにアクセスし、対象月を表示

1. `https://moneyforward.com/cf` にナビゲート
2. ログインが必要な場合はログイン画面が表示される。ユーザーのアカウントが表示されていれば確認の上クリック。パスワード入力が必要な場合はユーザーに操作を依頼する
3. 対象月を確認する。デフォルトは当月。当月に取引が少ない場合は前月に切り替えることを提案する

### Step 2: 未分類の取引を特定する

ここが効率化のポイント。取引一覧を上から下まで目視で探すのではなく、**大項目フィルターを使う**。

1. 取引一覧の上部にある「大項目」のフィルタードロップダウン（combobox）を見つける
   - `find` ツールで "大項目 filter dropdown" を検索するのが確実
2. `form_input` でフィルター値を「未分類」に設定する
   - もし「未分類」がフィルター選択肢に存在しない場合、未分類の取引は0件ということ。その旨をユーザーに報告して終了

フィルターが適用されると、未分類の取引だけが一覧に表示される。スクリーンショットを撮って全件を把握する（必要に応じてスクロール）。

### Step 3: ユーザーに確認する

未分類の取引一覧をユーザーに報告する。以下のフォーマットで簡潔にまとめる:

```
未分類の取引が○件ありました:
- [日付] [内容] [金額]
- [日付] [内容] [金額]
...
```

取引名から推測できるものは分類案を提示し、判断がつかないものはユーザーに質問する。

よくあるパターンの例:
- 「ベローチェ」「ドトール」「スターバックス」→ 食費/カフェ
- 「EXC・○○」→ エクセルシオールカフェ → 食費/カフェ
- 「スキヤ」「マツヤ」「デニーズ」→ 食費/外食
- 「セブンイレブン」「ファミリーマート」→ 食費/食料品 or 食費/コンビニ
- 「AMAZON」→ 用途によって異なるのでユーザーに確認
- 「UBER *EATS」→ 食費/フードデリバリー
- 英語名やカタカナで意味不明なもの → 必ずユーザーに確認

すべての分類案について、ユーザーの確認を一度にまとめて取る（1件ずつ聞くのではなく、バッチで提示する）。

### Step 4: カテゴリを修正する

ここがブラウザ操作の本番。以下の手順で効率よく進める。

#### 効率的な操作の原則

**1取引ずつ大項目・中項目を連続で完了させる**のが最も効率的。大項目だけ先にまとめて変更し、後から中項目を修正しに戻る方式は、ページスクロールや取引の再発見で二度手間になるため避ける。

1. **フィルターを外してから操作する**: 「未分類」フィルターをかけたままカテゴリを変更すると、変更した瞬間にその取引がフィルター結果から消えてページが再描画される。これが混乱の元になるので、未分類の取引を把握したら**フィルターを「全て」に戻してから**操作を始める。対象取引は日付と名前で特定する
2. **1取引を完結させてから次へ**: 大項目クリック → 選択 → 中項目クリック → 選択、を1取引ずつ完了させる
3. **同じ大項目の取引を連続で処理する**: 例えば「食費」にする取引が8件あるなら、まとめて処理するとドロップダウンの位置感覚がつかみやすい

#### 操作の詳細

取引一覧の各行には左から順に以下の要素がある:
- チェックボックス
- 日付
- 内容
- 金額
- 保有金融機関
- **大項目ドロップダウン** (x座標 約795付近)
- **中項目ドロップダウン** (x座標 約955付近)
- メモ・振替・削除アイコン

カテゴリ変更の操作:
1. 対象取引の**大項目ドロップダウン**をクリック → ドロップダウンメニューが表示される → 正しい大項目を選択
2. スクリーンショットで反映を確認（中項目が「その他○○」になっているはず）
3. 同じ取引の**中項目ドロップダウン**をクリック → ドロップダウンメニューが表示される → 正しい中項目を選択
4. スクリーンショットで反映を確認

もし大項目が既に正しく設定されていて中項目だけ「その他○○」な場合は、中項目の変更だけでOK。

#### ページスクロールへの対処

カテゴリを変更するとページが自動スクロールすることがある。対象の取引が画面外に行った場合は:
- まずスクリーンショットで現在位置を確認
- `find` ツールで対象の取引名を検索するか、スクロールして探す

### Step 5: 修正結果を確認する

すべての修正が終わったら:
1. 大項目フィルターを再度確認する（`find` で combobox を探して `form_input` で「未分類」を設定）
2. 「未分類」がフィルター選択肢に存在しない = 未分類が0件になった = 完了
3. もし「未分類」がまだ選択できて取引が残っている場合は、Step 3に戻る

### Step 6: ユーザーに結果を報告する

修正結果を簡潔にまとめて報告する:

```
○月の未分類取引をすべて修正しました（○件）:
- [内容] → [大項目]/[中項目]
- [内容] → [大項目]/[中項目]
...
```

## トラブルシューティング

- **ドロップダウンが開かない**: クリック座標がずれている可能性。`find` ツールで要素のref_idを取得し、`form_input` で直接値を設定する方法も試す
- **ログインセッションが切れた**: ページをリロードしてログインし直す
- **フィルターに「未分類」がない**: 未分類の取引がないことを意味する。ユーザーに報告して終了
- **取引が多すぎてスクロールが大変**: 「未分類」フィルターを使えば未分類だけに絞り込めるので、全件スクロールは不要

## 注意事項

- カテゴリの判断で迷ったら必ずユーザーに確認する。勝手に分類しない
- ユーザーへの質問はできるだけまとめて1回で行い、1件ずつ聞かない
- 大項目と中項目は必ず両方設定する。大項目だけ変更して中項目が「その他○○」のまま放置しない
